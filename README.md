# 🎮 Tic-Tac-Toe Game  

A simple yet interactive **Tic-Tac-Toe (X & O)** game built using **HTML, CSS, and JavaScript**.  
This project helped me practice **DOM manipulation, game logic implementation, event handling, and responsive UI design**.  

---

## 🚀 Features
- 🔄 Two-player game (X vs O).  
- 🏆 Detects winner or draw automatically.  
- 🎉 Displays winner/draw message with reset & new game option.  
- ✨ Responsive design using `vmin` units.  
- 🎨 Custom background, hover effects, and button animations.  

---
##🔗Live Link: https://bharathitech7.github.io/classic-tic-tac-toe/

## 🛠️ Tech Stack
- **HTML5** → Game structure.  
- **CSS3** → Styling, responsiveness, and UI polish.  
- **JavaScript (Vanilla JS)** → Game logic, winner check, draw check, and interactivity. 

## 🎯 Skills Showcased
- ✔️ DOM Manipulation (`querySelector`, `addEventListener`)  
- ✔️ Game logic with arrays & conditions  
- ✔️ Responsive design with `flexbox` & `vmin`  
- ✔️ Git & GitHub workflow (repo setup, commits, pushes)
